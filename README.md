# 🎨 Personal Portfolio Website

Welcome to my personal portfolio website! This project is a responsive, clean, and modern website built entirely from scratch using **HTML5** and **CSS3**. It showcases my skills, experience, and the web development projects I have built.

👉 **[Live Demo Link]**
https://github.com/Jiya1903/Portfolio/blob/main/index.html
https://github.com/Jiya1903/Portfolio/blob/main/style.css

---

## ✨ Features

* **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewports.
* **Modern UI/UX:** Clean typography, smooth scrolling, and subtle hover animations.
* **Key Sections:** 
  * **Hero Section:** A brief, punchy introduction about who I am.
  * **About Me:** A deeper look into my background and coding journey.
  * **Skills:** Visual breakdown of the technologies I work with.
  * **Contact Form:** A functional way for viewers to reach out.

---

## 🛠️ Built With

* **HTML5:** For semantic markup and structured content.
* **CSS3:** For custom styling, layouts (Flexbox/Grid), and animations.
* **Google Fonts & FontAwesome:** For clean typography and vector icons.
